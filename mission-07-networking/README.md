
# MISSION 7 - NETWORKING

## Objective

To understand basic computer networking concepts
and observe how computers communicate over a network.

## 1. What is a Computer Network?

A computer network is a group of interconnected
devices that communicate and share information
and resources with each other.

## 2. Important Networking Concepts

| Concept | Explanation |
|---|---|
| IP Address | A numerical address used to identify a device on a network |
| DNS | Domain Name System converts domain names into IP addresses |
| Router | Connects different networks and forwards data |
| Packet | A small unit of data transmitted over a network |
| Protocol | A set of rules used for communication |
| HTTP | Protocol used to transfer web resources |
| HTTPS | Secure version of HTTP |
| LAN | Local Area Network |
| WAN | Wide Area Network |

## 3. Networking Commands Practised

| Command | Purpose |
|---|---|
| ping | Tests network connectivity |
| nslookup | Checks DNS information |
| traceroute | Displays the route taken by network packets |
| curl -I | Checks HTTP response headers |
| ifconfig | Displays network interface information |

## 4. Practical Observations

### A. Ping Command

Command:
ping -c 4 google.com

Purpose:
Checks whether the destination server responds
to network packets.

Observation:
Used to observe packet responses and network latency.

### B. DNS Lookup

Command:
nslookup google.com

Purpose:
Finds the IP address associated with a domain name.

Observation:
DNS translates human-readable domain names
into IP addresses.

### C. Traceroute

Command:
traceroute google.com

Purpose:
Displays the network hops between the computer
and the destination.

Observation:
Helps understand how data travels through
different network devices.

### D. HTTP Headers

Command:
curl -I https://google.com

Purpose:
Displays HTTP response headers from a website.

Observation:
Helps understand how a web server responds
to an HTTP request.

### E. Network Interfaces

Command:
ifconfig

Purpose:
Displays network interface information.

Observation:
Helps identify network interfaces and their
configuration. Private identifying information
should not be published.

## 5. Difference Between LAN and WAN

| LAN | WAN |
|---|---|
| Covers a small geographical area | Covers a large geographical area |
| Commonly used in homes and offices | Connects networks across cities or countries |
| Example: College computer lab network | Example: Internet |
