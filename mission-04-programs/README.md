## Task 4.2 - Compare Compiler and Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates the program before execution | Executes instructions during runtime |
| Typical output | Often produces machine code or an executable file | Usually produces output directly during execution |
| One example | C compiler (GCC) | Python interpreter |
| One advantage | Compiled programs can execute efficiently | Easier to test and debug code interactively |

### Explanation

A compiler translates source code into another
form, often machine code, before the program runs.
An interpreter executes a program by reading and
carrying out instructions during runtime.
A compiler often produces an executable file,
while an interpreter can execute the program directly.
Both are important for running computer programs.
