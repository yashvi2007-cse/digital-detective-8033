## Number Systems

1. Decimal: Base 10, uses digits 0-9.
2. Binary: Base 2, uses digits 0 and 1.
3. Octal: Base 8, uses digits 0-7.
4. Hexadecimal: Base 16, uses digits 0-9 and A-F.

## Number Conversion Examples

| Conversion | Example |
|---|---|
| Decimal to Binary | 10 = 1010 |
| Decimal to Octal | 10 = 12 |
| Decimal to Hexadecimal | 255 = FF |
| Binary to Decimal | 1010 = 10 |
| Octal to Decimal | 12 = 10 |
| Hexadecimal to Decimal | FF = 255 |

## Character Encoding

Character encoding represents characters using
numerical values so computers can store and process them.

ASCII is a character encoding standard.

Example:
- A = 65
- B = 66
- a = 97

## Python Functions Used

| Function | Purpose |
|---|---|
| bin() | Converts an integer to binary |
| oct() | Converts an integer to octal |
| hex() | Converts an integer to hexadecimal |
| int() | Converts a number from a given base |
| ord() | Returns the Unicode code point of a character |
| chr() | Converts a code point into a character |
| input() | Accepts user input |
| print() | Displays output |

Note: The character conversion options in this
program are restricted to ASCII values 0-127.
