
# MISSION 1 - KNOW YOUR COMPUTER

## Task 1.1 - Trace an Activity Using IPOS

Activity: Typing and saving a document on a computer.

| Stage | What happens | Hardware / Component |
|---|---|---|
| Input | I enter text using the keyboard and select options using the mouse. | Keyboard and Mouse |
| Processing | CPU processes the entered information and RAM temporarily stores the working data. | CPU and RAM |
| Output | The completed document is displayed on the screen. | Monitor |
| Storage | The document is saved as a file on the computer. | SSD |

### Explanation

When I type a document, the keyboard sends input to
the computer. The CPU processes the information with
the help of RAM. The result is displayed on the monitor.
When I click Save, the document is stored permanently
on the SSD for future use.

## Task 1.2 - Identify Hardware and Software

| Item / Software Name | Hardware or Software? | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text |
| Mouse | Hardware | Not applicable | Controls the pointer |
| Monitor | Hardware | Not applicable | Displays information |
| CPU | Hardware | Not applicable | Processes instructions |
| macOS | Software | Operating System | Manages computer resources |
| Google Chrome | Software | Application | Used for browsing the internet |
| Visual Studio Code | Software | Application | Used for writing and editing code |
| Antivirus Software | Software | Utility | Protects the computer from malware |

Note: Replace macOS with Windows if you use a Windows computer.
