## 📌 About the Project

The Digital Detective is a hands-on computer science learning project designed to explore the fundamentals of computing through practical activities, programming exercises and command-line operations.

This assignment focuses on understanding how computers work, how software executes, how operating systems manage resources, how data is represented and how computers communicate over networks.

Throughout this journey, I explored essential computer science concepts using Terminal, Python, Git and GitHub.

## 🎯 Objectives

- Understand computer hardware and software.
- Explore the IPOS model of computing.
- Learn and practise Terminal commands.
- Understand operating systems and their responsibilities.
- Create and execute Python programs.
- Explore number systems and data representation.
- Learn version control using Git and GitHub.
- Understand fundamental computer networking concepts.
- Maintain organised documentation and practical evidence.
