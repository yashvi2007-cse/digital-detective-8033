
# MISSION 2 - TERMINAL

## Objective
To understand and practise basic Terminal commands
for navigating and managing files and directories.

## Commands Practised

| Command | Purpose |
|---|---|
| pwd | Displays current working directory |
| ls | Lists files and directories |
| ls -la | Displays detailed file information |
| mkdir | Creates a new directory |
| cd | Changes the current directory |
| touch | Creates an empty file |
| echo | Displays or writes text |
| cat | Displays file contents |
| find | Searches for files and directories |

## Practical Work

1. Checked the current working directory.
2. Listed files and directories.
3. Created a practice directory.
4. Created a text file.
5. Added text to the file.
6. Displayed the contents.
7. Returned to the main project directory.
8. Located the created file.

## Conclusion

I learned how to use Terminal commands to
navigate directories, create files, manage
folders and view file contents.
