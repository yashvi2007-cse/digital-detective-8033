
# MISSION 6 - GIT AND GITHUB

## Objective

To understand Git version control, repository
management, branches and Pull Requests.

## 1. What is Git?

Git is a distributed version control system
used to track changes in files and projects.

It helps developers maintain different versions
of their code and collaborate with others.

## 2. What is GitHub?

GitHub is an online platform that hosts Git
repositories and allows developers to collaborate,
share code and manage projects.

## 3. Important Git Commands

| Command | Purpose |
|---|---|
| git init | Initializes a Git repository |
| git status | Shows the current repository status |
| git add . | Stages changes |
| git commit -m | Saves changes with a message |
| git push | Uploads commits to GitHub |
| git pull | Downloads and integrates remote changes |
| git clone | Copies a remote repository |
| git branch | Lists available branches |
| git switch | Changes the current branch |
| git log | Displays commit history |
| git merge | Combines branches |

## 4. Understanding Git Workflow

The basic Git workflow contains three stages:

1. Working Directory:
   Where files are created and modified.

2. Staging Area:
   Where changes are prepared for a commit.

3. Repository:
   Where committed changes are stored.

## 5. What is a Branch?

A branch is a separate line of development
that allows developers to work on new features
without directly changing the main branch.

Example:
mission-06-practice

## 6. What is a Pull Request?

A Pull Request (PR) is a request to merge
changes from one branch into another branch.

It allows team members to review changes,
discuss improvements and approve code before
merging it into the main branch.

## 8. Difference Between Git and GitHub

| Git | GitHub |
|---|---|
| Version control system | Online hosting platform |
| Works locally | Works online |
| Tracks file changes | Hosts repositories |
| Supports branches and commits | Supports Pull Requests and collaboration |
